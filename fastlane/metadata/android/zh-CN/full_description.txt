DebForge 可将你 debrid 账户中的文件直接下载到手机、平板或 Android TV。你可以登录一个或多个服务，并随时在它们之间切换。

<b>支持的服务</b>
<ul>
<li>TorBox</li>
<li>Real-Debrid</li>
<li>AllDebrid</li>
<li>Premiumize</li>
<li>Debrid-Link</li>
</ul>

<b>功能</b>
<ul>
<li>高速下载：每个文件最多 16 个连接，支持暂停和继续，并自动刷新链接</li>
<li>媒体库视图：标题整洁，剧集按季分组，可搜索整个账户</li>
<li>来自 TMDB 的海报（在设置中添加你自己的免费 API 密钥）</li>
<li>可在应用内或通过分享添加磁力链接、.torrent 文件和链接，并可选择在就绪后立即下载</li>
<li>内置播放器：记住播放进度，“继续观看”一栏，自动加载种子自带字幕，下一集随时就绪；也可继续使用 VLC 等播放器</li>
<li>追剧：进入账户的新剧集会自动下载</li>
<li>桌面小部件、快捷设置图块和启动器快捷方式</li>
<li>登录了多个服务？直接添加到已缓存该内容的服务</li>
<li>下载前检查可用空间，可选自动删除旧下载</li>
<li>发布组说明文件、封面和样片不会出现在媒体库中</li>
<li>下载规则：仅限 Wi-Fi、仅在充电时、夜间时段以及限速</li>
<li>保存到任意文件夹，包括 SD 卡和 USB 存储设备，无需特殊权限</li>
<li>在应用中从服务里移除种子，或在下载完成后自动移除</li>
<li>添加前查看种子是否已被缓存（TorBox、Premiumize）</li>
<li>Wi-Fi 和移动数据的流量使用统计</li>
<li>备份和恢复设置，可选择用密码加密登录信息</li>
<li>可选的 Plex/Jellyfin 剧集和电影文件夹结构</li>
<li>将整个 TorBox 种子打包为一个 zip 下载</li>
<li>适用于手机、平板和 Android TV</li>
<li>七种配色主题，浅色与深色，适合 OLED 的纯黑模式，或使用壁纸配色</li>
<li>支持 14 种语言</li>
</ul>

<b>隐私</b>
API 密钥通过 Android Keystore 加密，且绝不会包含在备份中。没有任何分析统计，也没有广告。如果应用崩溃，一份已移除令牌、链接和文件名的报告会保存在你的设备上，只有在你选择分享时才会发送。

DebForge 需要至少拥有上述其中一项服务的账户。这些都是付费的专有服务，因此 F-Droid 为本应用标注了“Non-Free Network Services”（非自由网络服务）反特性。
